# Market-Assistant-Project

The Mini Market Terminal is a Java-based stock market information system developed across three milestones, beginning with loading and analyzing historical stock data, expanding into a full terminal with watchlist management, stock comparison tools, sorting and filtering features, and finally integrating an AI-powered assistant using the OpenAI Java library. The application supports searching tickers, viewing historical records, calculating key performance metrics, comparing multiple stocks, and interacting through a clear text-based or optional graphical interface. The final milestone adds AI-driven analysis, comparisons, news retrieval, or Q&A based on locally processed data, while emphasizing strong object‑oriented architecture, refactoring, and clean documentation.
